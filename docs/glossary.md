# Glossary

- **Tetromino**: A shape consisting of 4 blocks.
- **Block**: A single `#` character in the input file.
- **Board**: 2D grid where tetrominoes are placed.
- **Point**: Coordinates (X, Y) of a block.
- **Pipeline**: The sequence of processing steps.
- **TDD**: Test-Driven Development. Tests are written before implementation.
- **Validation**: Checking that input data is correctly formatted.
- **Normalize**: Shifting tetromino blocks so top-left is at (0,0).
- **debug_run.go**: A helper file to quickly run the pipeline with hardcoded tetrominoes for step-by-step debugging.
